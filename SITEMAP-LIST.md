## 7. Google Search Console — submit ka tareeqa

1. Property verify karein (DNS ya HTML tag).
2. **Sitemaps** → `sitemap-index.xml` likh kar Submit.
3. `sitemap.xml` bhi submit kar sakte hain (core/shop pages).
4. 2–3 movie pages **URL Inspection → Request indexing** se manually bhej dein.
5. `robots.txt` khol kar check karein ke `Sitemap: https://mizanora.vercel.app/sitemap-index.xml` likha ho.
