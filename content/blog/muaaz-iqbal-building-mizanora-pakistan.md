**Muaaz Iqbal**, Kasur, Pakistan se Mizanora ke founder aur developer hain. Mizanora ka idea sirf product listing tak limited nahi: is website mein shopping, learning tools aur Islamic content ko aik jagah rakhne ki koshish ki gayi hai. Unka [public profile](/muaaz-iqbal) aur [GitHub](https://github.com/muaaziqbalvip) unke kaam ke links dete hain.

## Customer ko kya nazar aata hai?

Visitor category browse karta hai, product ki photo aur price dekhta hai, choices select karta hai aur checkout karta hai. Product pages mein description aur specifications ke saath, agar admin ne provide ki hon, highlights, box contents aur care ya warranty ki information bhi aa sakti hai. Price aur stock badal sakte hain; hamesha checkout verify karein.

## Website ke peeche technology

Mizanora repository ke mutabiq website **Next.js aur React** par bani hai aur styling ke liye Tailwind use karti hai. Firebase live data aur admin functions ke liye use hota hai. Product archive mein purane catalogue data ki JSON files bhi hain; is se har product listing ke liye Firebase read karna zaroori nahi hota. Yeh technical design hai, unlimited free usage ka promise nahi.

## Noor aur Live TV

Noor shopping aur website navigation mein madad ke liye banayi gayi assistant hai. General sawalat ka AI jawab working Gemini configuration aur service availability par depend karta hai. AI ghalti kar sakti hai, is liye important information aur religious references verify karein.

Live TV mein admin channels configure kar sakta hai; player theme, guide aur stream quality options deta hai. Backup streams add hon to ek link fail hone par player doosra try kar sakta hai. Har stream ka owner alag hota hai aur playback source, permissions aur network par depend karta hai.

## Asaan Lang ka talimi idea

Muaaz ka [Asaan Lang project](https://github.com/muaaziqbalvip/asaan-lang) Urdu aur Roman Urdu mein programming concepts seekhne ki koshish hai. Misaal ke taur par `likho` output aur `agar` decision ke liye use hota hai. Project ke README ke mutabiq code MIT licensed hai aur local use ke liye Python 3.8 ya newer chahiye. [Beginner guide](/blog/asaan-lang-beginners-hands-on-roman-urdu) mein chhoti misaalein hain.
