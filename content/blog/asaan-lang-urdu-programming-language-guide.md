Angrezi keywords wali programming kisi bhi naye bande ke liye pehli deewar hoti hai:
`if`, `else`, `for`, `while` — matlab samajh aa jaye to bhi likhne mein jhijhak rehti hai.
**Asaan Lang** wahi deewar giraata hai: wohi logic, magar **Urdu ya Roman Urdu** mein.

```
likho("Assalam-o-Alaikum Pakistan")
agar umar >= 18:
    likho("Aap vote de sakte hain")
warna:
    likho("Abhi nahi")
```

Yeh chalne wali language hai — Python 3.8+ par banti hai, MIT licence ke saath khuli hai
(`github.com/muaaziqbalvip/asaan-lang`), aur iski apni website + playground hai:
[asaan-lang.vercel.app](https://asaan-lang.vercel.app).

## Kyun bani?

Pakistan mein programming seekhne wale logon ki sab se bari shikayat:
English errors samajh nahi aate. Asaan Lang ka pehla feature hi yeh hai ke **error Roman Urdu mein**
aata hai, line number ke saath:

```
Line 4: "agar" ke baad condition likhna zaroori hai
Line 7: "warna" se pehle koi "agar" nahi mila
```

Iska matlab naya banda atak kar chhorta nahi — usay samajh aa jata hai ke ghalti kahan hai.

## Kya kya kar sakte ho

| Kaam | Asaan Lang |
| --- | --- |
| Screen par likhna | `likho("...")` |
| Input lena | `poocho("Naam kya hai?")` |
| Condition | `agar` / `warna agar` / `warna` |
| Loop | `har i mein 1 se 10:` |
| Function | `kaam jama(a, b):` → `wapas a + b` |
| List | `cheezein = ["aik", "do"]` |
| Website banana | compiler HTML/CSS/JS generate karta hai |

Yani ek hi zaban se aap **console program** bhi likh sakte ho aur **website** bhi — students ke
liye yeh farq bara hai, kyunki pehla "main ne kuch banaya" ka lamha yahin aata hai.

## Kis ke liye hai (aur kis ke liye nahi)

**Haan:** school/college students, naye developers, teachers jo Urdu medium mein padhate hain,
aur woh log jo logic seekhna chahte hain magar English syntax se darte hain.

**Nahi:** production web apps (us ke liye JavaScript/TypeScript behtar hai), ya machine learning
(us ke liye Python hi theek hai). Asaan Lang **seekhne** ka pul hai, replacement nahi.

## Install kaise karein

1. Python 3.8+ install karein.
2. Repo clone karein: `git clone https://github.com/muaaziqbalvip/asaan-lang`
3. Apni file likhein: `assalam.asaan`
4. Chalayein: `python asaan.py assalam.asaan`

Website par playground bhi hai — bina install, browser mein likh kar chalayein aur output dekhein.
Compiler "website mode" mein HTML/CSS/JS bana deta hai, jise seedha hosting par daal sakte hain.

## Seekhne ka 7-din ka plan

| Din | Kaam |
| --- | --- |
| 1 | `likho` aur `poocho` — input/output |
| 2 | `agar` / `warna` — faislay |
| 3 | `har` loop — ginti, tables |
| 4 | `kaam` (function) — chhote kaam tor kar likhna |
| 5 | Lists — naam, marks, shopping list |
| 6 | Ek chhota project: calculator ya marks sheet |
| 7 | Website mode: apna pehla page |

Har din 30 minute kaafi hain. Asal farq **roz likhne** se parta hai.
