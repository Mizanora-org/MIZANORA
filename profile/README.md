#### 🛍️ Mizanora — *the shop*
**`Next.js 15` · `React` · `Tailwind` · `Firebase` · `PWA`**
[**Live store →**](https://mizanora.vercel.app) · [**Repo →**](https://github.com/muaaziqbalvip/MIZANORA)

A halal online market for Pakistan: **11,000+ products**, flat delivery, cash on delivery and an Urdu-speaking AI assistant called **Noor** that finds products from a messy sentence like *"sasta laal joota under 2k"*. Includes a worker/reseller programme, promo-code engine, order tracking, Quran + Hadith reader, live TV, a **24/7 live channel**, an own **ads API** (video, banner, product) and 38 free tools. The catalogue is cached so the shop keeps running even when a free quota runs out.

</td>
<td width="50%" valign="top">

#### 🧠 Asaan Lang — *the language*
**`Python 3.8+` · `MIT` · `Interpreter + site compiler`**
[**Repo →**](https://github.com/muaaziqbalvip/asaan-lang) · [**Site →**](https://asaan-lang.vercel.app)

Pakistan's own programming language. Beginners write `likho`, `agar / warna`, `har`, `kaam` in **Roman-Urdu or Urdu script** — no English wall first. Errors come back in Roman-Urdu with a line number, Urdu digits `۱۲۳` work, and `asaan --web` compiles a program into a real HTML site. Ships with a REPL and a browser playground.

```asaan
naam = lo "Aap ka naam? "
agar naam != "" to
    likho "Khush Amdeed, " + naam + "!"
warna
    likho "Mehman, salaam!"
bas
```

</td>
</tr>

<td width="50%" valign="top">

#### 📺 BarakatWave TV — *the network*
**`hls.js` · `FFmpeg` · `IMDb API` · `Vercel`**
[**Live →**](https://barakatwave.vercel.app)

A live TV and cinema platform for Pakistan and India: **800 channels**, multi-server relay failover, quality and audio-track switching, picture-in-picture, an IMDb-powered movie/series engine (`tt…` IDs → posters, cast, episodes) and Xtream Codes output that works in Televizo, TiviMate and VLC. There's even a 4-part broadcast suite with a welcome intro, offline card and discontinuity handoff so no player chokes.

</td>
<td width="50%" valign="top">

#### 🎬 SIRAVEX — *the player*
**`TypeScript` · `PWA` · `IndexedDB` · `HLS.js + Shaka`**
[**Live →**](https://siravex.vercel.app)

An installable, privacy-first media player for **your own authorised** playlists: M3U import (file or URL), Xtream Codes, XMLTV EPG, series grouping from `S01E02` titles, and offline app shell. Nothing is bundled and nothing is uploaded — playlists, favourites, progress and settings stay in your browser, and diagnostics show hosts only, never tokens.

</td>

## 🌱 How I work

```mermaid
flowchart LR
    A["A real problem<br/>I have seen myself"] --> B["Smallest useful<br/>version today"]
    B --> C["Test on a cheap<br/>phone, slow net"]
    C --> D["Ship it in public"]
    D --> E["Read the feedback<br/>and the logs"]
    E --> B
    E --> F["Only then:<br/>document it properly"]
    style A fill:#0B1F19,stroke:#64E7B0,color:#DCEFE6
    style B fill:#0B1F19,stroke:#64E7B0,color:#DCEFE6
    style C fill:#0B1F19,stroke:#F1C86A,color:#DCEFE6
    style D fill:#0B1F19,stroke:#F1C86A,color:#DCEFE6
    style E fill:#0B1F19,stroke:#8CB4FF,color:#DCEFE6
    style F fill:#0B1F19,stroke:#8CB4FF,color:#DCEFE6
```

1. **Think in years, act in days.** A big goal is only real if it has a version I can finish today.
2. **Build for my own people first.** Pakistani shoppers, Urdu-medium students, cheap Androids. If it works there, it works anywhere.
3. **Teach the machine, keep the judgement.** AI drafts the code, data and copy. I read it, test it and take responsibility for it.
4. **Be honest in public.** No fake countdowns, no invented discounts, no bought reviews, no "guaranteed profit". Projects that are experiments say so.
5. **Privacy is a feature.** IndexedDB over uploads, host-only diagnostics, no tracking pixels in products that don't need them.

## ⚡ How this profile stays alive

Every moving picture above is a **self-hosted SVG in `./assets`** — GitHub renders it as an `<img>` and plays the CSS keyframes inside it. No third-party animation service, nothing to 404.

- **The art is generated, not hand-drawn:** [`scripts/make-art.mjs`](scripts/make-art.mjs) writes all 12 files (dark + light). Change a colour or a sentence, run it, commit.
- **The numbers refresh themselves:** [`.github/workflows/refresh.yml`](.github/workflows/refresh.yml) runs every night, reads the public GitHub API (and the shop's [`/api/github`](https://mizanora.vercel.app/api/github)), then rewrites the values inside the SVGs at the tags marked `data-k="…"` — repositories, stars, followers, latest push, language mix.
- **Light and dark are separate files:** the README picks one with `<picture>` + `prefers-color-scheme`, so it looks right in both themes.
- **Accessibility:** every file stops all motion under `prefers-reduced-motion: reduce` and keeps the text visible.

```svg
<style>
  .dot { transform-box: fill-box; transform-origin: center; animation: beat 1.5s ease-in-out infinite; }
  @keyframes beat { 0%,100% { opacity:1; transform:scale(1) } 50% { opacity:.45; transform:scale(.62) } }
</style>
<circle class="dot" cx="20" cy="20" r="5" fill="#64E7B0" />
```

Three rules that save hours: `transform-box: fill-box` (spin around the shape, not `0,0`), `animation-fill-mode: both` for anything delayed, and monospace (`0.6 × font-size` per character) when you place text yourself.
