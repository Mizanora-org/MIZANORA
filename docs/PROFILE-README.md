## Profile repo banane ke 4 step

```bash
gh repo create muaaziqbalvip --public --add-readme --clone
cd muaaziqbalvip

# 2. upar wala markdown README.md mein paste karo
# 3. commit + push
git add README.md && git commit -m "profile readme" && git push

# 4. GitHub par kholo: https://github.com/muaaziqbalvip
```
