A small shop has one owner and a hundred jobs. Mizanora's admin panel has an **AI manager** that takes over the repeat work: you write what you want in Roman Urdu and it does it.

## What it can do
- Show an overview of products, orders and the shop status.
- Make products a **deal** and set up the [deals page](/deals).
- Set the **Quran session** schedule: which surah, which reciter, what time the shop starts.
- Add website animations and small code snippets.
- Add Islamic posts, publish blog posts and do online research with sources.
- Keep a to-do list.

## The safety rules
1. **Risky actions need your Confirm.** Changing prices, deleting things, adding code or religious texts are only prepared. You read exactly what will happen, then press Confirm.
2. **It cannot see secrets.** API keys, passwords, payment details and customers' phone numbers and addresses are outside its access.
3. **Every action is logged.**
4. **Honesty first.** It never invents an ayah, a hadith or a reference, and it refuses fake discounts or fake countdowns.

## Why this matters
Technology should serve honest business. An AI that can change prices must be controlled by a human who stays responsible. That is the Mizan idea: balance.
